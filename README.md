# drss-3986-odour-survey
DRSS-3986 Odour Survey Datascape and Fieldwork prototypes

## Latest RSHL Preview: V5

- [Datascape RSHL v5](https://andreapickensnz.github.io/drss-3986-odour-survey/DRSS-3986%20Odour%20Survey%20-%20Datascape%20-%20RSHL%20v5.html)
- [Fieldwork RSHL v5](https://andreapickensnz.github.io/drss-3986-odour-survey/DRSS-3986%20Odour%20Survey%20-%20Fieldwork%20-%20RSHL%20v5.html)

RSHL v5 builds on RSHL v4. The ten fixed Minute blocks stay in Initial Impression after Start time on Fieldwork, as on Datascape. On-site investigation required can be answered whether or not a 360 assessment was done, so Source on site investigation and On-site findings can be shown without one.
