# drss-3986-odour-survey
DRSS-3986 Odour Survey Datascape and Fieldwork prototypes

## Latest Preview: V7

- [Datascape](https://andreapickensnz.github.io/drss-3986-odour-survey/DRSS-3986%20Odour%20Survey%20-%20Datascape%20-%20v7.html)
- [Fieldwork](https://andreapickensnz.github.io/drss-3986-odour-survey/DRSS-3986%20Odour%20Survey%20-%20Fieldwork%20-%20v7.html)

V7 applies the latest workbook and review decisions: Survey Date is an editable key-information field; Timesheet, Assets and Inventory, General Visual Evidence, and Reinspection booking sections are removed. Datascape Yes/No fields use switches, and single-select fields use dropdowns on both surfaces. The Authority section remains; its questions have no open-question prompt. Minute times are manual in ten fixed rows, with fixed-row platform support still to be confirmed.
